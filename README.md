## What I'm working on

### 🔐 [Versola](https://github.com/versolauth/versola)
A self-hosted OAuth 2.0 / OpenID Connect server written in Scala (SSO, passkeys, role-based access). I work on issues in feature branches and open pull requests for review.

My contributions:
- **Security:** CSRF protection (hidden form inputs + `SameSite=Lax`), Blake3-signed SSO session cookie, FAPI-compliant PKCE (S256 only)
- **OAuth / OIDC:** RFC 9207 `iss` in authorization responses, nonce enforcement for hybrid flow, fragment-based error redirects, redirect URI validation
- **Crypto:** PS256 and ES256 JWT signing support
- **Account settings:** self-service password change, email/phone verification after OTP
